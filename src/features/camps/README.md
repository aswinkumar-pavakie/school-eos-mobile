# camps

Status: not yet implemented.

Parent-facing: consent collection (shown as a prominent banner when required
and not yet given) and findings view (attended, services received, results,
follow-up status - body measurements never shown comparatively). Faculty/health
staff record attendance and checkup findings on their own screens. Camp
creation/announcement/partner management is Admin-web-only.
